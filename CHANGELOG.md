## [0.1.0] - 2026-10-30

First public release.

### Added

- Harvester (Azure Functions, Python) that reads per-operation CU data from the Microsoft Fabric Capacity Metrics app with DAX: interactive and background operations, timepoints and dimensions.
- Enrichment of operations with item, run and query details from Fabric workspaces.
- Log Analytics custom tables, a data collection rule (DCR) and saved KQL functions for attribution, root cause, daily changes, coverage and harvest health.
- Azure Workbook with six tabs (Overview, Explain a window, 24h background, Root cause by run time, Daily changes, Details), generated by `infra/workbook/build_workbook.py`.
- Bicep template (`infra/main.bicep`) and deploy script (`infra/deploy.sh`).
- Load generator for a test workspace (`loadgen/`).
